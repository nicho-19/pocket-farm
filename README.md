# 口袋田园

一个向《星露谷物语》致敬的单页种田小游戏。直接双击 `index.html` 或 `pocket-farm-standalone.html`，用浏览器打开即可游玩；无需安装、服务器或网络资源。画面和全部像素素材由 Canvas 程序绘制。

## 玩法

农场有 **12 × 9** 个地块。移动到目标地块旁边，让农夫面向它；画面中的浅黄色边框标出当前操作目标。按顺序使用锄头开垦、播种、浇水，睡觉让作物生长。成熟后用镰刀收获，在商店点击“全部卖出”，再买种子继续种植。

| 操作 | 按键或按钮 |
| --- | --- |
| 逐格移动、改变朝向 | `W A S D` 或方向键 |
| 对面前一格使用当前工具 | 空格或回车 |
| 切换锄头、种子、水壶、镰刀 | `1`、`2`、`3`、`4`，或点击工具栏 |
| 选择播种作物 | 点击工具栏下的作物按钮 |
| 买种子、卖出背包收获 | 右侧商店按钮 |
| 进入下一天、恢复体力 | “睡觉”按钮 |
| 清空进度重开 | “新游戏”按钮，确认后覆盖当前存档 |
| 手机操作 | 左下方向键移动，右下“使用”操作；点击工具栏切换工具和作物 |
| 查看作物信息 | 右上“图鉴”按钮；点关闭、面板外或按 Esc 退出 |
| 开关音效 | 右上“音效 / 静音”按钮 |

## 系统与数值

| 作物 | 生长所需的浇水夜晚 | 种子价 | 出售价 |
| --- | ---: | ---: | ---: |
| 萝卜 | 3 | 10 G | 25 G |
| 土豆 | 4 | 18 G | 48 G |
| 南瓜 | 5 | 30 G | 85 G |
| 草莓 | 4 | 30 G | 81 G |
| 玉米 | 3 | 15 G | 38 G |

售价与种子价之比随生长天数上升：3 天作物为 2.50–2.53 倍，4 天作物为 2.67–2.70 倍，5 天南瓜为 2.83 倍。为维持这一梯度，萝卜售价由 28 调至 25 G，草莓由建议的 75 调至 81 G；草莓仍需较高初始投入。

- 初始状态：第 1 天春季晴天、**100 G**、**40/40** 体力、**3 包萝卜种子**。每 28 天换季，季节改变场景配色，不会导致作物枯萎。
- 每次锄地消耗 **4** 体力，播种 **2**，浇水 **2**，收获 **3**；移动和买卖不消耗体力。体力不足时动作被拒绝，睡觉回满至 **40**。
- 作物只有在当天被浇过水的夜晚才增加 **1** 格进度；未浇水则保持进度。夜间先结算当天的生长，再进入新的一天并重置湿润状态。
- 新一天有 **25%** 概率下雨。雨天会自动给已有作物浇水；雨天新播下的种子也视为已浇水，因此在该天结束时可以生长。晴天需要手动浇水。
- 五种作物各有种子、嫩芽、成长、成熟四种绘制形态。成熟后不会继续累加进度；收获会保留已开垦的地块，收获物进入背包。商店“全部卖出”按各作物售价结算。
- 每次有效操作、移动、换工具或选择作物后自动写入浏览器 `localStorage`。若浏览器禁止本地存储，当前打开的页面仍可游玩，但刷新后无法恢复。
- 收获会出现上浮“+1”和飞向背包的粒子；浇水有水花，卖出时金币数字跳动；睡觉有昼夜渐变，雨天亮起时有短暂雨丝。农夫有行走、挥工具和待机动画，成熟作物轻微浮动。
- 六类提示音由 WebAudio 实时合成，不下载音频文件。浏览器首次按键或点击后才初始化音频；静音设置保存在本地。
- 手机窄屏会按比例缩放农场画面，方向键和“使用”键与键盘共用操作逻辑；画布上触摸滑动不会拖动页面。

## 单文件版

`pocket-farm-standalone.html` 与多文件版内容一致，由 `node build-standalone.mjs` 把 CSS 和两个 JS 内联生成。修改源文件后重新运行该命令即可更新。可以只复制这一个 HTML 文件到手机或其他设备打开；存档仍保存在当前浏览器的 `localStorage`，不同文件来源的存档能否共用取决于浏览器对本地文件的存储策略。

## 与《星露谷物语》的对应与简化

保留逐格行走、农具操作、浇水后的夜间生长、雨天自动浇水、睡觉过天、种子购买和收获出售的核心循环。这里省略了 NPC、任务、矿洞、动物、每日时钟以及季节限定作物；商店和睡觉按钮可随时使用，以便专注种田。

## 局限与可扩展点

## 第三遍优化（v3）：画面、操控、玩法

本轮由 Codex（gpt-6-sol）按 TASK3-DETAIL.md 实施，助手独立复验（详见文末核验记录）。稻草人/乌鸦为可选加分项，本轮未做。

### 画面
- 农夫与作物加脚下椭圆影子；面向的可交互地块有呼吸高亮框；误操作时地块抖动反馈。
- 场景加密：外围栅栏、左下角带波纹动画的水塘、石板小路、四季变色的树与花丛。
- 面板改木质边框风；Canvas 按 devicePixelRatio 高清渲染（上限 2 倍），绘制坐标取整不发虚。

### 操控（转向优先为最高原则）
- 输入方向与当前朝向不同：本次输入只转身、不位移；朝向一致后继续按住（约 120ms 后）以约 140ms 间隔逐格移动；再次点按同方向也移动。键盘与虚拟方向键共用同一套输入状态机。
- 智能使用键：面对成熟作物自动收获、未浇水的作物自动浇水、空草地用当前工具（手动切过工具时按当前工具执行）。
- 点任意地块：相邻则转身使用；不相邻则 BFS 寻路自动走近（避开作物地块与障碍）。
- 使用键长按连发（约 180ms 一次），体力耗尽自动停；虚拟键加大到 56px 以上，面板打开时自动隐藏。

### 玩法
- 订单板：每天刷新 1–3 个订单（指定作物×数量、限期 2–4 天、奖励约卖价总和 1.5 倍），背包够数点交付，过期自动失效。
- 工具升级：铁水壶 600 G（一次浇面前横排 3 格）；精钢锄 400 G（锄地体力消耗减半）。
- 饭团 20 G：吃掉回 15 体力。
- 天气预报：状态栏显示明日天气；季节雨率 春 30% / 夏 40% / 秋 25% / 冬 20%。
- 图鉴新增统计页：累计收入、累计收获、完成订单数、已玩天数。

## 第四遍优化：画面细节与动画

### 画面逐项对照

- 地块：草地由底色、双色稳定噪点、按坐标生成的草簇、石子和花瓣组成；翻土加犁沟阴影与土块高光；湿土加三处水光。
- 作物：五种作物的种子、嫩芽、成株、成熟期都加了各自细节。萝卜有叶脉和红至白的根，土豆有藤蔓、白花与土包裂纹，南瓜有卷须、瓜纹和高光，草莓有心形叶、深浅红果与籽点，玉米有层叠苞叶、穗须与颗粒。
- 农夫：草帽、脸、蓝衣、棕裤、鞋分色；正面、侧面、背面区分脸部和帽檐；工具在朝向侧显示，锄头、水壶、镰刀各有独立轮廓。
- 场景：房屋增加瓦纹、暖光十字窗、门把手；水塘有岸边高光；树有双层树冠与树干纹；栅栏有立柱阴影和木纹；石板路大小错落且缝隙生草。
- 光影：农夫、作物、树和栅栏的阴影统一向右下偏移。

### 动画逐项对照

- 环境：水塘每 1.2 秒扩散涟漪；树冠、草叶、花朵错相轻摆；烟囱持续冒烟并淡出；云影约 8 秒掠过一次；成熟作物约 0.9 秒出现一颗十字闪光。
- 农夫与农事：行走四帧交替摆腿、摆臂和起伏；锄、水壶、镰刀分别按举起、挥下、收回三段运动，约 200 ms；浇水时壶嘴到地块有抛物线水滴，随后出现水花；收获物先弹起，再旋转飞向背包并消散，同时保留“+1”飘字。
- 天气：雨天持续斜雨丝与落地溅点，冬季持续缓落、左右摇摆的雪花；两者按当前天气与季节显示。
- 界面：面板打开时淡入并从 0.98 缩放；工具图标切换时弹跳；金币在 300 ms 内滚动到新值；体力条约 200 ms 缓动；过夜先渐暗，显示约 20 颗闪烁星星停留约 400 ms，再渐亮。
- 性能：烟雾、雨雪、星光等粒子共用一个最多 300 个的队列，满额丢弃最旧项；动画均在原有 rAF 循环中更新，输入逻辑继续逐帧运行，页面隐藏时暂停排下一帧。
