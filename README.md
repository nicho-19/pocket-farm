# 口袋田园

一个白天种田布防、夜里守护收成的单页小游戏。直接双击 `index.html` 或 `pocket-farm-standalone.html`，用浏览器打开即可游玩；无需安装、服务器或网络资源。场景、作物与主角农夫优先使用本地生成素材，村民、强盗、水面及加载失败时的完整后备画面由 Canvas 程序绘制。

## 玩法

农场有 **40 × 28** 个地块。移动到目标地块旁边，让农夫面向它；画面中的浅黄色边框标出当前操作目标。草地、草甸和农田均可用锄头开垦；面前格无事可做时会自动尝试脚下格。按顺序开垦、播种后，作物每夜生长、雨天更快。夜里乌鸦和强盗可能来袭；白天可建造防御道具、购买武器。成熟后用镰刀收获，收成可吃来回血，也可卖钱。

| 操作 | 按键或按钮 |
| --- | --- |
| 逐格移动、改变朝向 | `W A S D` 或方向键 |
| 对面前一格使用当前工具 | 空格或回车 |
| 切换锄头、种子、镰刀、采集、鱼竿、建造 | `1`–`6`，或点击工具栏 |
| 自动回家 | `H` 或 HUD“回家”按钮 |
| 选择播种作物 | 点击工具栏下的作物按钮 |
| 买种子、卖出背包收获 | 右侧商店按钮 |
| 睡觉过夜、恢复 10 HP | “睡觉”按钮 |
| 守夜战斗 | 强盗之夜点“守夜”，面向强盗按使用键 |
| 快捷吃回血 | `Q` 或生命条旁“吃” |
| 与村民对话 | 靠近一格按使用键 |
| 清空进度重开 | “新游戏”按钮，确认后覆盖当前存档 |
| 手机操作 | 左下方向键移动，右下“使用”操作；点击工具栏切换工具和作物 |
| 查看作物信息 | 右上“图鉴”按钮；点关闭、面板外或按 Esc 退出 |
| 开关音效 | 右上“音效 / 静音”按钮 |

## 早期版本系统与数值（历史记录，现行规则见文末第九遍）

| 作物 | 生长所需进度 | 种子价 | 出售价 |
| --- | ---: | ---: | ---: |
| 萝卜 | 3 | 10 G | 25 G |
| 土豆 | 4 | 18 G | 48 G |
| 南瓜 | 5 | 30 G | 85 G |
| 草莓 | 4 | 30 G | 81 G |
| 玉米 | 3 | 15 G | 38 G |

售价与种子价之比随生长天数上升：3 天作物为 2.50–2.53 倍，4 天作物为 2.67–2.70 倍，5 天南瓜为 2.83 倍。为维持这一梯度，萝卜售价由 28 调至 25 G，草莓由建议的 75 调至 81 G；草莓仍需较高初始投入。

- 初始状态：第 1 天春季晴天、**100 G**、**40/40** 体力、**3 包萝卜种子**。每 28 天换季，季节改变场景配色，不会导致作物枯萎。
- 每次锄地消耗 **4** 体力，播种 **2**，收获 **3**；移动和买卖不消耗体力。体力不足时动作被拒绝，睡觉回满至 **40**。
- 作物每过一夜增加 **1** 格进度；新一天为雨天时额外增加 **1** 格。旧档作物沿现有进度继续生长。
- 雨天概率按季节为春 30%、夏 40%、秋 25%、冬 20%；雨天只影响生长速度。
- 五种作物各有种子、嫩芽、成长、成熟四种绘制形态。成熟后不会继续累加进度；收获会保留已开垦的地块，收获物进入背包。商店“全部卖出”按各作物售价结算。
- 每次有效操作、移动、换工具或选择作物后自动写入浏览器 `localStorage`。若浏览器禁止本地存储，当前打开的页面仍可游玩，但刷新后无法恢复。
- 收获会出现上浮“+1”和飞向背包的粒子；成熟作物有闪光，卖出时金币数字跳动；睡觉有昼夜渐变，雨天亮起时有短暂雨丝。农夫有行走、挥工具和待机动画，成熟作物轻微浮动。
- 六类提示音由 WebAudio 实时合成，不下载音频文件。浏览器首次按键或点击后才初始化音频；静音设置保存在本地。
- 手机窄屏会按比例缩放农场画面，方向键和“使用”键与键盘共用操作逻辑；画布上触摸滑动不会拖动页面。

## 单文件版

`pocket-farm-standalone.html` 与多文件版内容一致，由 `node build-standalone.mjs` 把 CSS 和两个 JS 内联生成。修改源文件后重新运行该命令即可更新。可以只复制这一个 HTML 文件到手机或其他设备打开；存档仍保存在当前浏览器的 `localStorage`，不同文件来源的存档能否共用取决于浏览器对本地文件的存储策略。

## 第十五遍：生图素材接入

房屋与三间小屋、阔叶树/松树、五种作物的四个阶段、树桩/野果/石堆、稻草人/栅栏和草地纹理已接入 `pilot-assets/game/` 的 32 项 PNG。这批素材由 AI 生成后做透明背景抠图与整理；农夫、村民、强盗、池塘水面仍保持程序绘制。

多文件版按相对路径加载 PNG；单文件构建会将 32 项素材转成 base64 data URI 内嵌，当前生成文件为 **6,756,965 字节（约 6.44 MiB）**。每张图片都独立记录就绪状态：未加载、加载失败、绘制异常或运行环境没有 `Image` 时，对应绘制点立即使用第十四遍 Canvas 画法，不留白、不阻断游戏。静态世界缓存、相机源矩形裁切和动态可见格裁剪均保留。

## 第十六遍：主角奶蛙素材

主角农夫改用 `pilot-assets/preview16f/` 定稿的 12 帧浅奶黄奶蛙素材（草帽、大白肚）；素材由 AI 生图，经多轮抠图、切帧与方向一致性复核后选定 `preview16f`，并复制到 `pilot-assets/game/`。村民、强盗及对话头像仍保持程序绘制，未使用的四张角色单图已从游戏素材目录移除。

奶蛙按底部中心锚定到格内 `x+24, y+46`，目标高度 46px；站立使用帧 0，65ms 走路四相位映射为 `[1, 0, 2, 0]`，沿用原呼吸与走路浮动。影子、手持工具和挥动动画继续在原程序路径绘制。当前帧未就绪、图片绘制异常或环境无 `Image` 时，农夫整身回退为原像素画；Node 冒烟已显式覆盖四个方向。

游戏素材现为 **44 项**，单文件版为 **7,695,628 字节（约 7.34 MiB）**。逻辑测试 63/63、独立版冒烟与实测台端到端均通过；尚未在真实桌面浏览器或手机验证奶蛙的实际观感、工具遮挡、触控和 GPU 性能。

## 第十七遍 A：人物与操作

- 农夫素材与程序回退统一为 62px 高，村民和强盗按 1.35 倍绘制；脚底锚点、碰撞和交互距离不变。
- 自动工具默认开启，按 `0` 或点“自动”可重新开启；按 `1`–`6` 手选工具会关闭自动。自动播种时当前种子用完会按作物表顺序换用仍有库存的种子。
- 按住方向键与空格可沿垄连续开垦、播种或收获，操作连发间隔为 150ms。
- 钓鱼改为时机玩法：首次按使用键抛竿，看到钓点上方“！”及“咬钩了！”提示后，在 900ms 内再次按使用键收竿。过早或过晚都会跑鱼且不扣钓点次数；成功后若钓点仍有次数会自动继续抛竿。

## 第十七遍 B：社交、成就与天气

- 村长喜欢池鱼，商人婆婆喜欢野果，小猎手喜欢玉米；送中喜好加 2 心并永久揭示喜好，其他礼物加 1 心。婆婆好感达 3 心后，所有种子按单价向上取整的 9 折价购买。
- 图鉴新增 12 项成就，覆盖收获、钓鱼、采集、制作、订单、守夜、经济、游玩天数和村民好感；达成时自动发放 20–500 G。
- 每次睡觉以晴 50% / 多云 30% / 雨 20% 掷定次日天气。雨天作物在每日 +1 基础进度外再 +1，钓鱼咬钩等待缩短为 700–1800ms；多云与晴天没有数值加成。

## 第十八遍：全图耕种与脚下作业

- 锄头可开垦 `farm`、`grass`、`meadow` 三类地形，农田分区与底图身份不变；道路、树林、池塘、房屋和住宅区仍不可开垦。
- 使用工具时先结算面前格；仅当该格没有可执行目标时，才用同一套规则尝试脚下格。种子不足和面前资源节点操作失败不会回退，建造、村民交谈与守夜战斗维持原路径。

## 第三遍优化（v3）：画面、操控、玩法

本轮由 Codex（gpt-6-sol）按 TASK3-DETAIL.md 实施，助手独立复验（详见文末核验记录）。稻草人/乌鸦为可选加分项，本轮未做。

### 画面
- 农夫与作物加脚下椭圆影子；面向的可交互地块有呼吸高亮框；误操作时地块抖动反馈。
- 场景加密：外围栅栏、左下角带波纹动画的水塘、石板小路、四季变色的树与花丛。
- 面板改木质边框风；Canvas 按 devicePixelRatio 高清渲染（上限 2 倍），绘制坐标取整不发虚。

### 操控（转向优先为最高原则）
- 输入方向与当前朝向不同：本次输入只转身、不位移；朝向一致后继续按住（约 120ms 后）以约 140ms 间隔逐格移动；再次点按同方向也移动。键盘与虚拟方向键共用同一套输入状态机。
- 智能使用键：面对成熟作物自动收获、未浇水的作物自动浇水、空草地用当前工具（手动切过工具时按当前工具执行）。
- 点任意地块：相邻则转身使用；不相邻则 BFS 寻路自动走近（避开作物地块与障碍）。
- 使用键长按连发（约 180ms 一次），体力耗尽自动停；虚拟键加大到 56px 以上，面板打开时自动隐藏。

### 玩法
- 订单板：每天刷新 1–3 个订单（指定作物×数量、限期 2–4 天、奖励约卖价总和 1.5 倍），背包够数点交付，过期自动失效。
- 工具升级：铁水壶 600 G（一次浇面前横排 3 格）；精钢锄 400 G（锄地体力消耗减半）。
- 饭团 20 G：吃掉回 15 体力。
- 天气预报：状态栏显示明日天气；季节雨率 春 30% / 夏 40% / 秋 25% / 冬 20%。
- 图鉴新增统计页：累计收入、累计收获、完成订单数、已玩天数。
