# 口袋田园

一个向《星露谷物语》致敬的单页种田小游戏。直接双击 `index.html` 或 `pocket-farm-standalone.html`，用浏览器打开即可游玩；无需安装、服务器或网络资源。画面和全部像素素材由 Canvas 程序绘制。

## 玩法

农场有 **12 × 9** 个地块。移动到目标地块旁边，让农夫面向它；画面中的浅黄色边框标出当前操作目标。按顺序使用锄头开垦、播种、浇水，睡觉让作物生长。成熟后用镰刀收获，在商店点击“全部卖出”，再买种子继续种植。

| 操作 | 按键或按钮 |
| --- | --- |
| 逐格移动、改变朝向 | `W A S D` 或方向键 |
| 对面前一格使用当前工具 | 空格或回车 |
| 切换锄头、种子、水壶、镰刀 | `1`、`2`、`3`、`4`，或点击工具栏 |
| 选择播种作物 | 点击工具栏下的作物按钮 |
| 买种子、卖出背包收获 | 右侧商店按钮 |
| 进入下一天、恢复体力 | “睡觉”按钮 |
| 清空进度重开 | “新游戏”按钮，确认后覆盖当前存档 |
| 手机操作 | 左下方向键移动，右下“使用”操作；点击工具栏切换工具和作物 |
| 查看作物信息 | 右上“图鉴”按钮；点关闭、面板外或按 Esc 退出 |
| 开关音效 | 右上“音效 / 静音”按钮 |

## 系统与数值

| 作物 | 生长所需的浇水夜晚 | 种子价 | 出售价 |
| --- | ---: | ---: | ---: |
| 萝卜 | 3 | 10 G | 25 G |
| 土豆 | 4 | 18 G | 48 G |
| 南瓜 | 5 | 30 G | 85 G |
| 草莓 | 4 | 30 G | 81 G |
| 玉米 | 3 | 15 G | 38 G |

售价与种子价之比随生长天数上升：3 天作物为 2.50–2.53 倍，4 天作物为 2.67–2.70 倍，5 天南瓜为 2.83 倍。为维持这一梯度，萝卜售价由 28 调至 25 G，草莓由建议的 75 调至 81 G；草莓仍需较高初始投入。

- 初始状态：第 1 天春季晴天、**100 G**、**40/40** 体力、**3 包萝卜种子**。每 28 天换季，季节改变场景配色，不会导致作物枯萎。
- 每次锄地消耗 **4** 体力，播种 **2**，浇水 **2**，收获 **3**；移动和买卖不消耗体力。体力不足时动作被拒绝，睡觉回满至 **40**。
- 作物只有在当天被浇过水的夜晚才增加 **1** 格进度；未浇水则保持进度。夜间先结算当天的生长，再进入新的一天并重置湿润状态。
- 新一天有 **25%** 概率下雨。雨天会自动给已有作物浇水；雨天新播下的种子也视为已浇水，因此在该天结束时可以生长。晴天需要手动浇水。
- 五种作物各有种子、嫩芽、成长、成熟四种绘制形态。成熟后不会继续累加进度；收获会保留已开垦的地块，收获物进入背包。商店“全部卖出”按各作物售价结算。
- 每次有效操作、移动、换工具或选择作物后自动写入浏览器 `localStorage`。若浏览器禁止本地存储，当前打开的页面仍可游玩，但刷新后无法恢复。
- 收获会出现上浮“+1”和飞向背包的粒子；浇水有水花，卖出时金币数字跳动；睡觉有昼夜渐变，雨天亮起时有短暂雨丝。农夫有行走、挥工具和待机动画，成熟作物轻微浮动。
- 六类提示音由 WebAudio 实时合成，不下载音频文件。浏览器首次按键或点击后才初始化音频；静音设置保存在本地。
- 手机窄屏会按比例缩放农场画面，方向键和“使用”键与键盘共用操作逻辑；画布上触摸滑动不会拖动页面。

## 单文件版

`pocket-farm-standalone.html` 与多文件版内容一致，由 `node build-standalone.mjs` 把 CSS 和两个 JS 内联生成。修改源文件后重新运行该命令即可更新。可以只复制这一个 HTML 文件到手机或其他设备打开；存档仍保存在当前浏览器的 `localStorage`，不同文件来源的存档能否共用取决于浏览器对本地文件的存储策略。

## 与《星露谷物语》的对应与简化

保留逐格行走、农具操作、浇水后的夜间生长、雨天自动浇水、睡觉过天、种子购买和收获出售的核心循环。这里省略了 NPC、任务、矿洞、动物、每日时钟以及季节限定作物；商店和睡觉按钮可随时使用，以便专注种田。

## 局限与可扩展点

存档是单槽本地存档，不跨浏览器同步；事件日记只保留当前页面会话，刷新后从欢迎语开始。后续可加多存档和季节限定种植规则。
